# Алгоритмы и структуры данных

Репозиторий с лабораторными работами по дисциплине **«Алгоритмы и структуры данных»**.

**Язык программирования:** C++  
**Среда разработки:** Visual Studio

## О проектах

Все лабораторные работы выполнены на **C++** в рамках продвинутого уровня, варианта 5.

В каждой работе представлены реализация требуемых алгоритмов и структур данных, демонстрация их работы и анализ основных особенностей.

Репозиторий будет пополняться по мере выполнения следующих лабораторных работ.
